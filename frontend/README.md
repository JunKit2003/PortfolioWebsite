# Portfolio frontend

This directory contains the standalone React, TypeScript, Vite, Tailwind, and
ShadCN UI frontend for the portfolio.

## Prerequisites

- Node.js 20.19+ or 22.12+
- npm 10+

## Run locally

From the repository root, install dependencies and start the Vite development
server:

```bash
cd frontend
npm install
npm run dev
```

Create a production build with:

```bash
cd frontend
npm run build
```
